# Elegy Observe

**Readiness: implemented; not agent-routable.** Bounded process, window,
clipboard, screen, filesystem, and system queries work from source. Several
operations are Windows-specific and no clean installed observation workflow is
recorded. Build with `cargo build -p elegy-observe`; invoke
`elegy-observe --help` and one bounded query. This is an adapter candidate in
rework, not a packaged plugin.
