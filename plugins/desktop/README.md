# Elegy Desktop

**Readiness: implemented; not agent-routable.** Windows mouse, keyboard, and
window-control primitives work from source. Semantic application understanding
and a clean installed real-application workflow are unavailable. Build with
`cargo build -p elegy-desktop`; invoke `elegy-desktop --help` and one bounded
command. Evidence covers source tests only. This is an adapter candidate in
rework, not a packaged plugin.
