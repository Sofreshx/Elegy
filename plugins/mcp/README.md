# Elegy MCP Descriptor Tooling

**Readiness: implemented; not agent-routable.** Explicit MCP descriptors can be
authored and statically analyzed. Live server discovery, hosting, and automatic
implementation are unavailable. Build with `cargo build -p elegy-mcp`; invoke
`elegy-mcp author` or `elegy-mcp analyze`. Evidence covers source behavior, not
an external MCP service. This is a development tool, not a plugin.
