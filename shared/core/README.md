# Elegy Core and Contracts

**Readiness: implemented; not agent-routable.** Contract export, validation,
and project inspection work for supported descriptor contracts. This is shared
library/tooling behavior, not a plugin, and no clean installed consumer task is
recorded. Build with `cargo build -p elegy-core`; invoke `elegy-contracts` with
an explicit validation or inspection subcommand. Evidence is source-scoped.
