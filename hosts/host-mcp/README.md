# Elegy Run

**Readiness: implemented; not agent-routable.** The stdio host lists and reads
supported static resources in source tests. It does not make incubating
capabilities usable and no clean installed host task is recorded. Build with
`cargo build -p elegy-host-mcp`; invoke `elegy-run` with a supported project
descriptor. This is an optional MCP host adapter, not a plugin.
